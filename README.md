# DS_prep

## Overview

This repository is a learning documentation workspace for data science preparation. Contains sample notebooks, datasets, and exploratory examples that demonstrate basic data loading, indexing, filtering, and summary analysis.

## Learning Goals

- Learn pandas fundamentals through hands-on practice
- Learn datasets handling and processing 
- Build knowledge and confidence with basic data analysis workflows

## Course Credit

This repo is inspired by and aligned with the Kaggle Learn pandas course:

- https://www.kaggle.com/learn/pandas

## Notes

- Paths in the notebook currently use absolute Windows paths. Update them to relative paths or your local environment before running.
- The current dataset is focused on sleep health and lifestyle attributes, just for the purpose of learning data analysis workflows.
